# 🐯 Sba3iya Magic Salon

Application de gestion pour salon de coiffure et d'esthétique.

## ✨ Fonctionnalités

- 🏠 **Tableau de bord** — Vue d'ensemble du salon
- 👥 **Clients** — Gestion + historique
- 💇 **Serveuses** — Gestion + spécialités
- ✂️ **Services** — Gestion des prix
- 📅 **Rendez-vous** — Prise de RDV + statuts
- 💰 **Caisse** — Encaissement multi-services
- 📊 **Rapport** — Statistiques + export CSV
- ⚙️ **Paramètres** — Mot de passe + personnalisation

## 🎨 Design

- Noir + Or élégant
- Bilingue Français / Arabe (السباعية ماجيك صالون)
- Interface moderne avec CustomTkinter

## 🛠️ Technologies

- **Python 3.14**
- **CustomTkinter** (interface)
- **SQLite** (base de données)
- **Pillow** (images)
- **PyInstaller** (compilation en .exe)
